# Portfolio Logo Uploads

1. Add a logo image to this folder (`.png`, `.jpg`, `.webp`, or `.svg`).
2. Open `index.html` and find the project's `EDIT PROJECT IMAGE HERE` comment.
3. Set that project's image `src` to the logo file path, for example:
   `src="assets/project-logos/dunn-ranch.png"`
4. Save and reload. The logo automatically centers and scales inside the project card without cropping or stretching. The project detail modal uses the same image path and fit.

Keep the path relative to `index.html`. New project cards still need their title and other project details added in `index.html`; the logo image itself will auto-fit. If an image is missing, the card displays a text preview instead of a broken-image icon.
